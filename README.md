# ⚙️ Python Automation Toolkit

![Python](https://img.shields.io/badge/Python-3.11-blue)
![License](https://img.shields.io/badge/License-MIT-yellow)

A collection of practical Python automation scripts for REST APIs, web scraping, data processing, and workflow automation.

## 📦 Toolkit Contents

| Script | Description |
|--------|-------------|
| `api_client.py` | Generic REST API client with auth, retry & rate limiting |
| `web_scraper.py` | Async web scraper with BeautifulSoup |
| `data_processor.py` | CSV/Excel/JSON data cleaning & transformation |
| `email_automation.py` | Automated email sending with templates |
| `scheduler.py` | Task scheduler with cron-like syntax |

## 🚀 Quick Start

```bash
git clone https://github.com/rashedkhanrubel-spec/python-automation-toolkit
cd python-automation-toolkit
pip install -r requirements.txt
```
